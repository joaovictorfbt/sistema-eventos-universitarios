# Sistema de Eventos Universitários

Projeto de front-end desenvolvido para uma atividade de HTML e CSS.

## Tecnologias

- HTML5
- CSS3
- Flexbox
- Media Queries

## Páginas

- `index.html` — página inicial com os eventos.
- `programacao.html` — tabela de programação.
- `inscricao.html` — formulário de inscrição.
